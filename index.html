操作顺序

  1. 在吊牌上翻面，再点「模拟扫码」。
  2. 等整幅画自动展开，试试点「收起」。
  3. 点开「查看授权后版式（占位）」。
  4. 自己选一种穿法，走到提交与完成。
  5. 在完成后重选版式，或用右上角重置。

状态与异常

加载失败和提交失败开关在手机上方；E01/E02 都有重试和另一条路。每次只模拟一次失败，重试会成功。

边界写死：不接支付、不生成订单、不收联系方式、不向项目方提交意向；分享仅复制课程说明与当前 HTTPS 用户入口。外部入口二维码由部署方提供，加载成功后才展示。画作为自绘 SVG 抽象占位，创作者姓名与故事均为占位；不出现资金比例、机构背书或收益承诺。本页只做原型，不替代概念提案、设计报告或验证报告，也没有任何真实测试结果。

事实与边界 / 用户声明

这是什么入口？

这是「爱分你公益产品入口」的课程概念，不是已获认证的公益项目页面。设计尝试用“画角 → 全画 → T 恤”连接作品理解、分享与穿着意向。

目前可提供：自绘 SVG 示意作品、两种印花位置预览、本页意向回执和可复制的课程说明。

尚未核实：项目运营主体、公益资质、受益对象、作品授权及资金流向。本页不作机构背书，不声称任何创作者因此获得收益。

演示边界：没有捐赠、支付、订单或联系方式收集；意向仅存当前页内存，不发送给项目方。复制由你主动发起，后续发送由你决定。HTTPS 页面提供当前入口地址；本地或 HTTP 环境只提供说明。

这份声明由课程原型制作方提供，不是项目认证或真实用户测试结论。在线访问可能产生静态托管平台的常规访问日志，本页没有自设分析或提交接口。
